# Domain documentation

This is a single-context repository. Read the root `CONTEXT.md` for domain terms. Read the documentation index in `llm/README.md` for current behavior. Read applicable ADRs if present; absent ADRs are not a blocker.

Modernization specs describe target behavior. They do not establish that a change is implemented or deployed. A ticket must identify and update the existing behavior guide when its implementation changes that behavior.
