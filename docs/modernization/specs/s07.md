# S07: Canonical Scripture and versioned scene plans

<!-- visibible-modernization:S07 -->

## Problem Statement

Missing text, upstream failures and invalid references are mixed together. Supplied text can influence shared plans, and old plans can survive changes to their inputs.

## Solution

Resolve canonical passages consistently, preserve reader location on errors, and reuse a scene plan only when its meaningful inputs match.

## User Stories

1. As a reader, I want to stay at my intended verse when text is unavailable, so that a temporary failure does not send me to Genesis.
2. As a reader, I want to know when my translation lacks a passage, so that I can choose another translation.
3. As a guest, I want to generate from the declared Scripture text, so that the image is tied to the correct passage.
4. As a reader, I want to navigate consistently across book and chapter edges, so that the controls follow one reference system.
5. As a guest, I want to reuse compatible scene plans, so that I avoid unnecessary planner calls.
6. As a maintainer, I want to invalidate plans after prompt or model changes, so that new behavior is evaluated on current inputs.
7. As an operator, I want to bound cached chapter data, so that long-running processes do not accumulate unlimited entries.
8. As a reader, I want to keep stable verse URLs, so that existing links remain useful.

## Implementation Decisions

- A Scripture module owns book identity, parsing, canonical single-verse validation, translation lookup and adjacent navigation. Reuse existing navigation semantics and static metadata; consolidate duplicate book lists only behind preserved behavior.
- The interface distinguishes invalid reference, unavailable translation text and retryable upstream failure. Preserve the requested URL and offer retry or translation selection. Never silently substitute another verse or translation for paid generation.
- Canonical image requests supply reference, translation and generation settings. The server resolves current and adjacent text. Existing clients may temporarily send text for compatibility, but it is checked/ignored as authoritative input; custom text cannot populate the shared plan cache.
- Prefer the existing platform chapter cache. If a process-local layer remains necessary, cap it at 256 chapter entries with 24-hour TTL and deduplicate in-flight fetches. Bound upstream waits and keep failed responses from becoming long-lived successful cache entries.
- Scene-plan identity includes canonical passage content fingerprint, translation, planner model, prompt version, style version and any relevant chapter-theme/continuity inputs. Cache lookup is a query; hit accounting is a separate bounded write.
- Prompt construction is a pure internal part of the generation module with bounded length and structured plan validation. Keep the existing classical style and Genesis 1 theme as the baseline. Preserve the visual intent and variation semantics; evaluate any changed prompt output under S10.
- Shared image browsing continues to group by verse reference across translations, with translation/provenance visible on image details. Generation itself always uses the selected translation.

## Testing Decisions

Tests assert externally observable behavior through the highest practical existing interface. Exercise actual application handlers and replace external paid/network effects with controlled adapters. Avoid tests that repeat implementation arithmetic or only inspect source text.

- Test the highest Scripture resolve-and-navigate interface with realistic translation fixtures and upstream failure adapters.
- Cover first/last verses, book transitions, missing chapter/verse coverage, timeout and transient error states.
- Verify incompatible client text never alters shared cached plans, and each relevant version change invalidates a hit.
- Retain navigation/bulk-scope tests; replace source assertions with rendered location/error behavior.

## Out of Scope

- A new Bible text provider or corpus ingestion
- New translations
- A general cross-chapter character/scene continuity engine
